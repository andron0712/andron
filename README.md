# Лабораторна робота: База даних "University"

Цей репозиторій містить розв'язання завдання Варіанту №1 по створенню, наповненню та маніпуляції даними у СУБД (MySQL / PostgreSQL).

## Структура проєкту
* `database.sql` — повний SQL-скрипт із командами створення схем, триггерів зв'язків, заповнення дефолтними даними та тестовими запитами.

## Опис виконаних кроків валідації зв'язків
При видаленні студента з таблиці `students`:
1. Записи про його оцінки у таблиці `grades` видаляються автоматично завдяки правилу **`ON DELETE CASCADE`**.
2. Записи у таблицях `scholarships` та `attendance` зберігаються для звітності, але поле зв'язку `student_id` набуває значення **`NULL`** завдяки параметру **`ON DELETE SET NULL`**.
